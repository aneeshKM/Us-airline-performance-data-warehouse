# Benchmark Procedure

The benchmark command intentionally deletes all rows owned by this project, rebuilds the chosen
historical range, ingests one later month, and generates measured reports. It does not drop the
database, warehouse, schemas, stage, or table definitions.

For a 2023–2024 full build followed by a January 2025 increment:

```bash
airline-warehouse benchmark \
  --start 2023-01 \
  --end 2024-12 \
  --incremental-month 2025-01 \
  --confirm-reset
```

The full runtime is the sum of successful monthly `TOTAL_DURATION_SECONDS` values sharing the
new benchmark ID. The incremental runtime is the later one-month run. The report calculates:

```text
(full_load_seconds - incremental_load_seconds) / full_load_seconds * 100
```

The report also executes and times reads from each analytics mart. These client-observed query
durations include connection and result-fetch behavior and should be described that way.

Outputs:

```text
reports/pipeline_metrics.json
reports/benchmark.md
```

Do not add numbers to a resume until both outputs were generated by a completed run and the
Snowflake reconciliation checks passed.
